# Инструкции для продолжения работы

- Сначала прочитай `docs/WORK_LOG.md` (точка продолжения), затем `docs/ARCHITECTURE.md` и `docs/RULES_V1.md`. Полное исходное задание — `CLAUDE_CODE_MASTER_PROMPT.md`.
- Общение с пользователем — по-русски, прямо. Все тексты в UI — на русском.
- **Правила живут только в `packages/game-core`.** Сервер — единственный авторитет. Клиент может импортировать ядро только для чтения/подписей, никогда не меняет состояние и не дублирует проверки.
- **Не смешивай каноническое состояние с UI/анимацией.** Анимации выводятся из событий снимка; состояние матча не ждёт клиентов.
- Числа правил — только в `packages/content/src/ruleset.ts` и данных карты; после изменения обнови `docs/RULES_V1.md`, тесты и подсказки UI.
- Время в ядре только через параметр `now`; случайность — только `ctx.rng`. Никаких `Date.now()`/`Math.random()` в `game-core`.
- Новая команда = тип в `game-core/types.ts` + схема в `protocol` + обработчик + тест.
- Не публикуй секреты возобновления, seed/rng, скрытые ответы мини-игр в публичных снимках (`views.ts`).
- Dev-инструменты (`dev:cheat`, боты) только при `PB_DEV=1`.
- Проверки перед коммитом: `npm run typecheck && npm test` (и `npm run e2e` для UI). Пиши результаты в `docs/VALIDATION.md`, не выдавай эмуляцию за проверку на устройстве.
- Ветка `claude/browser-economy-board-game-aspm4s`, без force push.
