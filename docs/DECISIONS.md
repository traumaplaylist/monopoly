### Архитектура
- **Сервер авторитетен, ядро чистое.** Время приходит параметром (`now`), ГСЧ — в состоянии; тесты гоняют целые партии на управляемых часах.
- **Socket.IO 4** для комнат и команд, **встроенный `node:sqlite`** вместо `better-sqlite3`. Причина: на Windows не нужен компилятор для нативного модуля. Минус — ExperimentalWarning на Node 22; требование Node ≥ 22.13 (LTS 24 — без флагов).
- **Одна строка в `rooms` на комнату** с полным состоянием + журнал событий. Запись — одна транзакция до ответа клиенту. ORM не нужен.
- **Обработчики синхронные** — естественная последовательная обработка команд комнаты без очередей и блокировок.
- **Полные публичные снимки** после каждого изменения (матч небольшой). Дельты не нужны, пока не доказано обратное.
- **Мини-игры в публичном состоянии:** расписание сигналов «Кассы» публичное — модифицированный клиент может «видеть будущее». Принято для альфы: очки считает сервер, ввод проверяется по окнам и частоте, поддельный счёт невозможен. Маршрут «Курьера» скрыт после показа.
- **Отладочные функции** (боты на пустых местах, `dev:cheat`: деньги, комплект, «стать призраком», «пропустить ожидание», «закончить после раунда») работают только при `PB_DEV=1`; сервер в обычном режиме их отклоняет. Использованы для ручной проверки и скриншотов; честная партия до финала проверяется отдельно (серверный тест и E2E с `endSoon`, см. `VALIDATION.md`).

### Интерфейс и графика
- **Ортографическая камера почти сверху (наклон 24°).** Поле вписывается по проекции углов: всё видно без зума.
- **Два профиля раскладки:** `landscape` (поле 12.9×9.4) и `portrait` (9.2×14.75). Индексы, группы и обход одинаковые — меняются только размеры плиток. Профиль выбирается по пропорциям области поля.
- **Вертикальный телефон — основной мобильный режим** (подсказка «поверните телефон» из прототипа удалена).
- **Пиксельные персонажи рисуются программно** (6 типажей, рубашка = цвет игрока, отдельный призрак) — временные, заменяются PNG/GLB через `assets.json`.
- **Иконки клеток — эмодзи** (заменяемые). На разных ОС выглядят по-разному — известное ограничение.
- **Шрифт Rubik входит в сборку** (без Google Fonts): офлайн и WebView. Пиксельный шрифт не использован — у популярных пиксельных шрифтов слабая кириллица.
- **Звуки синтезируются WebAudio** (без сторонних файлов), включаются после первого нажатия, есть громкость и «меньше анимации».

### Политики (рабочие)
- Отсутствие: до 5 мин — место держится, решения принимает таймер; дольше — выход с ликвидацией. Все отключились на 60 с — пауза комнаты со сдвигом сроков; 30 мин — выгрузка из памяти; 3 дня — удаление из базы.
- Хозяин лобби отключился/вышел — права передаются следующему подключённому.
- Реванш: все сидящие люди голосуют; при полном столе новый матч стартует сразу, иначе — лобби.
