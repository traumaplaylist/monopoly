# Журнал работы / точка продолжения

## 26.10.2026 — онлайн-альфа V1 (ветка `claude/browser-economy-board-game-aspm4s`)

**Работает:** монорепо (content / game-core / protocol / server / client); ядро V1 (32 клетки, экономика, аукцион с резервом, сделки, долг и авто-ликвидация, банкротство → призрак, 12 раундов, итог по ликвидационной стоимости); мини-игры «Касса закрывается» и «Курьер без навигатора» с серверной проверкой; дуэли с 3 жетонами; щит/скидка/конус; проделки призрака; сервер Socket.IO + SQLite с идемпотентными командами, переподключением, вытеснением старой сессии, паузой пустой комнаты и восстановлением после перезапуска; клиент (вход, лобби, матч ПК/телефон, панели, мини-игры, итог и реванш); конфигурация Capacitor.

**Не проверено:** реальные телефоны, iPhone, APK (нет Android SDK в среде), реальная партия людей, баланс и длительность.

**Следующие действия:**
1. Партия с друзьями по `docs/PLAYTEST.md`; записать сюда наблюдения.
2. Собрать APK на Windows по `docs/BUILD_MOBILE.md`, проверить на телефоне.
3. Подстроить баланс (`packages/content/src/ruleset.ts`), обновить `RULES_V1.md`.
4. Заменить эмодзи-иконки и заглушки моделями (`docs/ASSETS.md`).
