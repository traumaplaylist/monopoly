# Выгрузка игры в интернет (Render.com, бесплатно)

После этого у игры будет постоянная ссылка вида `https://party-board-xxxx.onrender.com`. Друзья открывают её в браузере (Chrome/Edge/Firefox на ПК) — устанавливать ничего не нужно. Твой компьютер включать не нужно.

## Что важно знать про бесплатный тариф
- Если 15 минут никто не играл, сервер засыпает. Первый, кто откроет ссылку после этого, ждёт **около минуты** (страница грузится долго) — это нормально, дальше всё быстро. Во время игры сервер не засыпает.
- **Недоигранная партия пропадает**, если сервер уснул или перезапустился (бесплатный диск стирается). Играйте партию за один вечер.
- 750 бесплатных часов в месяц; спящий сервер их не тратит.
- Каждый раз, когда я пушу изменения в ветку, Render сам пересобирает игру (≈5 минут). Если в это время идёт партия — она прервётся. Перед игрой с друзьями напиши мне «не пушь» или проверь, что сборка закончилась.

## Шаг 1. Регистрация (один раз, ~3 минуты)
1. Открой https://render.com → **Get Started** (или **Sign Up**).
2. Выбери **GitHub** и войди своим аккаунтом GitHub (тот же, где репозиторий `traumaplaylist/monopoly`).
3. Render попросит доступ к репозиториям — разреши доступ к репозиторию **monopoly** (можно «Only select repositories» → monopoly).
4. Банковскую карту для бесплатного тарифа не требуют. Если вдруг попросит — остановись и напиши мне.

## Шаг 2. Создание игры по готовому файлу (~2 минуты)
1. В панели Render нажми **New +** (вверху) → **Blueprint**.
2. Выбери репозиторий **traumaplaylist/monopoly** → **Connect**.
3. Render найдёт файл `render.yaml`. Если спросит ветку (**Branch**) — выбери `claude/browser-economy-board-game-aspm4s`.
4. **Blueprint Name** — любое, например `party-board`. Нажми **Apply** / **Deploy Blueprint**.

## Шаг 3. Дождаться сборки (~5–8 минут)
1. Открой сервис **party-board** → вкладка **Logs** (Журнал). Идёт установка и сборка.
2. Готово, когда вверху статус **Live** (зелёный), а в журнале строка `server on http://0.0.0.0:...`.
3. Ссылка игры — вверху страницы сервиса, вида `https://party-board-xxxx.onrender.com`. Открой её — должен появиться экран «Вокруг света».

Если статус **Failed** — открой **Logs**, скопируй последние ~30 строк и пришли мне. Самая вероятная причина — **нехватка памяти при сборке** (в журнале `Out of memory`, `exit code 137` или `Killed`): у бесплатного тарифа 512 МБ, а сборка клиента местами требует больше. Тогда я переключу выгрузку на заранее собранную версию — это 10 минут работы с моей стороны.

## Шаг 4. Играть
1. Открой ссылку, введи имя, **Создать комнату**.
2. Нажми **Скопировать ссылку** и отправь друзьям в чат. Им достаточно открыть ссылку и ввести имя.
3. Каждый может зайти в **Гардероб** и собрать персонажа.
4. Все жмут **Готов**, хозяин — **Начать игру**. Нужно ровно 4 человека.

## Если что-то не так
| Что видно | Что делать |
|---|---|
| Страница грузится больше минуты | Сервер просыпался. Подожди ещё минуту и обнови страницу (F5). |
| «Нет связи» в игре | Обнови страницу — вернёт на твоё место в той же партии (если сервер не перезапускался). |
| Партия исчезла | Сервер перезапустился (бесплатный тариф). Создайте комнату заново. |
| Красный статус Failed | Пришли мне журнал (Logs). |

## Для разработчика
- Файл `render.yaml`: один бесплатный web-сервис; сборка `npm ci --include=dev && npm run build -w @pb/client && npm run build -w @pb/server` (без проверки типов — она делается перед коммитом; пик памяти сборки клиента локально ~0,8 ГБ по сумме процессов, риск OOM на 512 МБ есть), запуск `npm start`, проверка `/health`; переменные `HOST=0.0.0.0`, `STATIC_DIR=../client/dist`, `DB_PATH=/tmp/party-board.sqlite`, `NODE_VERSION=22.22.0`. `PB_DEV` не задаётся — dev-инструменты на сервере отключены.
- Render передаёт `RENDER_EXTERNAL_URL` — сервер добавляет его в разрешённые источники (`apps/server/src/config.ts`).
- Платный тариф (≈7 $/мес, Starter) + диск — чтобы сервер не засыпал и партии переживали перезапуск: `plan: starter` и `disk` в `render.yaml`, `DB_PATH` на диск.
