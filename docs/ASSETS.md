# Графика: замена заглушек моделями из Blender и картинками

Вся графика сейчас — встроенные заглушки (пиксельные персонажи рисуются кодом, low-poly домики и конусы из примитивов, эмодзи на клетках). Каждую можно заменить файлом **без правки кода**: положите файл в `apps/client/public/` и пропишите его в `apps/client/public/assets.json`. Чего нет в манифесте — рисуется заглушкой.

```json
{
  "models": { "upgrade1": "models/house.glb", "cone": "models/cone.glb" },
  "icons": { "1": "icons/cafe.png" },
  "avatars": { "0": "avatars/ryzhaya.png" }
}
```

## Слоты моделей (`.glb`)
| Слот | Что | Размер (1 ед. = 1 м в Blender) | Начало координат |
|---|---|---|---|
| `token` | фигурка игрока (материал `Tint` перекрашивается в цвет игрока) | высота ≈ 0.9, подставка Ø ≈ 0.45 | центр низа |
| `ghost` | фигурка призрака | ≈ 0.6 | центр низа |
| `upgrade1`, `upgrade2`, `upgrade3` | улучшения 1–3 уровня | ≈ 0.4 × 0.2, высота до 0.4 | центр низа |
| `cone` | ловушка (материал `Tint`: оранжевый у конуса, фиолетовый у ловушки призрака) | ≈ 0.25 × 0.25 × 0.3 | центр низа |
| `tree` | декор вокруг поля | ≈ 0.8 × 1.2 | центр низа |
| `deck` | зарезервировано | | |

Размеры клеток: ПК — верх/низ 1.3 × 1.6, бока 1.9 × 0.92; телефон — верх/низ 0.9 × 1.25, бока 1.45 × 1.75; высота блока 0.2.

**Экспорт:** File → Export → glTF 2.0 → glTF Binary; +Y Up; Apply Modifiers; перед экспортом `Ctrl+A → All Transforms`. «Лицо» модели — в сторону −Y Blender (к зрителю). Principled BSDF, текстуры до 1024 px, фигурка до ~5 000 треугольников.

Стиль с 02.11.2026 — «солнечный стол» (`docs/VISUAL_DIRECTION.md`): `token` — глянцевый мипл (встроенная заглушка — выдавленный силуэт, `render/jelly.tsx`), `upgrade1–3` — 1–3 гранёных кристалла (перекрашиваются в цвет владельца через материал `Tint`). Иконки клеток по умолчанию — Lucide (`render/icons.ts`), PNG из `icons` их заменяют. Слот `tree` больше не используется (декор стола — купюры и карточки). Прежний пиксельный стиль не целевой.

## Иконки клеток (`icons`) — PNG 256×256, прозрачный фон
Ключ — номер клетки 0–31 (список в `docs/RULES_V1.md`).

## Портреты (`avatars`) — PNG 256×256
Ключ — номер персонажа 0–5 (выбирается в лобби): 0 Рыжая, 1 Тихий, 2 Пончик, 3 Искра, 4 Кепка, 5 Хвостик.

## Происхождение ресурсов
| Ресурс | Источник | Лицензия |
|---|---|---|
| Пиксельные персонажи, призрак | генерируются кодом (`render/pixelArt.ts`) | собственные |
| Плитки, домики, конусы, деревья, кубики | примитивы Three.js в коде | собственные |
| Иконки клеток | эмодзи системного шрифта (временно) | шрифт ОС пользователя |
| Шрифт Nunito | `@fontsource/nunito` | SIL Open Font License 1.1 |
| Звуки | синтез WebAudio в коде | собственные |
| Концепты `output/concepts/*.png` | присланы пользователем, только референсы, в сборку не входят | — |

## Иконки клеток (с 02.11.2026)
По умолчанию — цветные 3D-иконки **Microsoft Fluent Emoji 3D** (MIT, © Microsoft; лицензия лежит рядом: `public/icons/fluent/LICENSE.txt`). Файл = `public/icons/fluent/<visual>.png`, где `visual` — ключ клетки из `packages/content/src/map.ts`; список подключённых ключей — `FLUENT` в `apps/client/src/render/icons.ts`. С 04.11.2026 добавлены иконки карт «По России» и «Космос» и 8 смайлов реакций (`emote-*.png`), тоже Fluent Emoji 3D, уменьшены до 256×256. Иконки из `assets.json` → `icons` применяются только к карте «Вокруг света» (номера клеток общие, а картинки — про её города). Свою иконку для конкретной клетки можно по-прежнему задать в `assets.json` → `icons` (по номеру клетки) — она главнее.

## Персонажи и гардероб (с 03.11.2026)
- Модели: **Quaternius «Ultimate Modular Men/Women»** (CC0, лицензия — `apps/client/public/models/characters/LICENSE-Quaternius.txt`). Источник файлов — GLB-конверсия из публичного репозитория `LuanDucate/Ducz.CharacterCreator` (берём только модели с их исходной CC0; код того репозитория не используется).
- Сборка: `node scripts/build-characters.mjs <папка с Male/*.glb и Female/*.glb>` → `apps/client/public/models/characters/<наряд>.glb` (без анимаций и оружия, meshopt), общий файл анимаций `clips.glb` (Idle, Wave, Walk) и каталог `packages/content/src/characterCatalog.ts`. Военные наряды (Soldier, Swat) исключены.
- Миниатюры гардероба: запустить клиент в dev и `node scripts/make-thumbs.mjs http://localhost:5173` → `models/characters/thumbs/<наряд>-<слот>.png`.
- Новый наряд из Blender: та же структура (скелет Quaternius, узлы `<Имя>_Head/_Body/_Legs/_Feet`, материалы `Skin`, `Hair*`, ткань), положить в папку-источник и пересобрать — появится в гардеробе.
