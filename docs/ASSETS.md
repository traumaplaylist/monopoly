# Графика: как заменить заглушки своими моделями и картинками

Сейчас вся графика — встроенные заглушки (человечки из примитивов, домики-кубики, эмодзи на клетках).
Каждую можно заменить своим файлом **без правки кода**: положить файл в `public/` и прописать его в `public/assets.json`.
Чего нет в `assets.json` — рисуется заглушкой, поэтому менять можно по одной вещи.

```json
{
  "models": {
    "token": "models/token.glb",
    "house": "models/house.glb"
  },
  "icons": {
    "1": "icons/crater.png",
    "39": "icons/pluto.png"
  },
  "avatars": {
    "0": "avatars/0.png"
  }
}
```

После правки — обновить страницу (при `npm run dev`) или пересобрать (`npm run build`).

## 3D-модели (Blender → `.glb`)

| Слот | Что это | Размер в Blender (1 единица = 1 м) | Начало координат |
|---|---|---|---|
| `token` | Фигурка игрока (одна на всех, перекрашивается) | высота ≈ 0.45, подставка Ø ≈ 0.4 | центр низа подставки |
| `ghost` | Фигурка выбывшего игрока | ≈ 0.35 | центр |
| `house` | Модуль (дом) | ≈ 0.16 × 0.16, высота ≈ 0.25 | центр низа |
| `hotel` | Станция (отель) | ≈ 0.45 × 0.22, высота ≈ 0.45 | центр низа |
| `deck` | Колода карточек в центре поля | ≈ 2.3 × 1.5, высота ≈ 0.3 | центр низа |
| `decor-rock`, `decor-crystal` | Декор вокруг поля (расставляется случайно, масштаб 0.3–0.85) | ≈ 1 × 1 | центр низа |

Для сравнения: клетка верхнего ряда — 1.3 × 1.55, боковая — 2.0 × 0.78, высота блока клетки — 0.22.

**Правила экспорта:**
1. File → Export → **glTF 2.0**, формат **glTF Binary (.glb)**.
2. Галочки: *+Y Up* (по умолчанию), *Apply Modifiers*. Анимации пока не используются.
3. Перед экспортом: `Ctrl+A → All Transforms`, чтобы масштаб был 1, а поворот 0.
4. «Лицо» модели смотрит в сторону **−Y в Blender** (это +Z в игре, к зрителю).
5. Материалы — Principled BSDF. Текстуры упаковываются в `.glb` сами.
6. **Перекраска в цвет игрока:** материал, который нужно перекрасить (например, куртка или подставка фишки), назовите ровно `Tint`. Игра заменит его цвет на цвет игрока.
7. Держите модели лёгкими: фигурка — до ~5 000 треугольников, домик — до ~500, текстуры — до 1024 px. Игра пойдёт и на телефонах.

## Иконки клеток (`icons`)
- PNG с прозрачным фоном, квадрат **256 × 256**.
- Ключ — номер клетки от 0 до 39 (0 — «Старт», дальше по часовой стрелке; список — в `src/engine/board.ts`).
- Иконка рисуется на месте эмодзи, название и цена остаются текстом.

## Портреты игроков (`avatars`)
- PNG или JPG, квадрат **256 × 256**.
- Ключ — номер места игрока: 0 — вы, 1–5 — боты по порядку.

## Где что в коде (если понадобится)
- Слоты моделей и загрузка: `src/render/assets.tsx`.
- Заглушки: `src/render/Tokens.tsx` (фигурки), `src/render/Buildings.tsx` (дома), `src/render/Board.tsx` (поле, колоды, декор).
- Оформление клеток (цвета, эмодзи, раскладка надписей): `src/render/tileArt.ts`.
- Размеры поля: `src/render/layout.ts`.
