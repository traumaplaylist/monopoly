# Графика: замена заглушек моделями из Blender и картинками

Вся графика сейчас — встроенные заглушки (пиксельные персонажи рисуются кодом, low-poly домики и конусы из примитивов, эмодзи на клетках). Каждую можно заменить файлом **без правки кода**: положите файл в `apps/client/public/` и пропишите его в `apps/client/public/assets.json`. Чего нет в манифесте — рисуется заглушкой.

```json
{
  "models": { "upgrade1": "models/house.glb", "cone": "models/cone.glb" },
  "icons": { "1": "icons/cafe.png" },
  "avatars": { "0": "avatars/ryzhaya.png" }
}
```

## Слоты моделей (`.glb`)
| Слот | Что | Размер (1 ед. = 1 м в Blender) | Начало координат |
|---|---|---|---|
| `token` | фигурка игрока (материал `Tint` перекрашивается в цвет игрока) | высота ≈ 0.9, подставка Ø ≈ 0.45 | центр низа |
| `ghost` | фигурка призрака | ≈ 0.6 | центр низа |
| `upgrade1`, `upgrade2`, `upgrade3` | улучшения 1–3 уровня | ≈ 0.4 × 0.2, высота до 0.4 | центр низа |
| `cone` | ловушка (материал `Tint`: оранжевый у конуса, фиолетовый у ловушки призрака) | ≈ 0.25 × 0.25 × 0.3 | центр низа |
| `tree` | декор вокруг поля | ≈ 0.8 × 1.2 | центр низа |
| `deck` | зарезервировано | | |

Размеры клеток: ПК — верх/низ 1.3 × 1.6, бока 1.9 × 0.92; телефон — верх/низ 0.9 × 1.25, бока 1.45 × 1.75; высота блока 0.2.

**Экспорт:** File → Export → glTF 2.0 → glTF Binary; +Y Up; Apply Modifiers; перед экспортом `Ctrl+A → All Transforms`. «Лицо» модели — в сторону −Y Blender (к зрителю). Principled BSDF, текстуры до 1024 px, фигурка до ~5 000 треугольников.

Выбранный стиль — плоские пиксельные персонажи на подставках (не объёмные). Для `token` можно сделать подставку моделью, а персонажа — плоскостью с пиксельной текстурой (фильтрация Closest).

## Иконки клеток (`icons`) — PNG 256×256, прозрачный фон
Ключ — номер клетки 0–31 (список в `docs/RULES_V1.md`).

## Портреты (`avatars`) — PNG 256×256
Ключ — номер персонажа 0–5 (выбирается в лобби): 0 Рыжая, 1 Тихий, 2 Пончик, 3 Искра, 4 Кепка, 5 Хвостик.

## Происхождение ресурсов
| Ресурс | Источник | Лицензия |
|---|---|---|
| Пиксельные персонажи, призрак | генерируются кодом (`render/pixelArt.ts`) | собственные |
| Плитки, домики, конусы, деревья, кубики | примитивы Three.js в коде | собственные |
| Иконки клеток | эмодзи системного шрифта (временно) | шрифт ОС пользователя |
| Шрифт Rubik | `@fontsource/rubik` | SIL Open Font License 1.1 |
| Звуки | синтез WebAudio в коде | собственные |
| Концепты `output/concepts/*.png` | присланы пользователем, только референсы, в сборку не входят | — |
