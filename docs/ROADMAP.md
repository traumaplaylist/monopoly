# Дорожная карта и статус

| Этап | Критерий готовности | Статус |
|---|---|---|
| 0. Обследование и решения | Среда, стек, фазы, границы V1 описаны | ✅ |
| 1. Общий стол | 4 независимых клиента видят один бросок; перезагрузка не создаёт нового игрока; комнаты изолированы | ✅ (серверные тесты + E2E) |
| 2. Экономика | Партия завершается реальными командами без двойных списаний и вечных фаз | ✅ (симуляция ботами, серверная ускоренная партия до FINISHED и реванш) |
| 3. Отличия продукта | Мини-игры, дуэли, предметы, призрак в одной партии | ✅ ядро + UI; баланс не проверен |
| 4. Визуал и удобство | Целевые размеры проверены, вертикальный телефон работает | ✅ в эмуляции браузера; на реальных телефонах — нет |
| 5. Платформы и итог | Prod build, Capacitor, честный Android/iOS статус | ⚠ см. `BUILD_MOBILE.md` |

## Следующие приоритеты
1. **Реальная партия с друзьями** по `PLAYTEST.md` — главный риск продукта.
2. Баланс по итогам: длительность, частота мини-игр, цены дуэлей, сила призрака.
3. Проверка на физических телефонах (Android Chrome, iOS Safari), затем сборка APK на машине с Android SDK.
4. Графика: модели и иконки из Blender через `assets.json`.
5. Только после этого — новые карты и «Угадай человека».
