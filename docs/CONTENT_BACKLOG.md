# Будущий контент (НЕ готово, не утверждено)

Ничего из этого списка не реализовано. Общие правила под темы не меняем до тестов основной карты.

## Карты-кандидаты
| Тема | Идея визуала | Возможная особенность |
|---|---|---|
| Современный город («Мегаполис») | **реализована как первая карта** | — |
| Вокруг света | Страны-вымышленные регионы на кольце, самолётики | Клетка «пересадка»: перелёт на противоположную сторону |
| Космическая станция | Модули станции, иллюминаторы, невесомость | Шлюз: ход назад вместо вперёд по выбору |
| Пиратский архипелаг | Острова, бухты, корабли-фишки | Шторм: всех сдвигает на 1 клетку |
| Королевство | Замки, деревни, ярмарки | Налог короля растёт с раундом |
| Киберпанк | Неон, кварталы, дроны | Взлом: короткая мини-игра вместо налога |
| Парк безумия | Аттракционы, американские горки | Горка: случайный телепорт на 3–6 клеток |

## Мини-игры
- **«Угадай человека»** — вопросы о друзьях за столом (утверждено как интерес, отложено до проверки первых двух игр).
- Идеи на потом: «Точный тайминг» (остановить стрелку), «Сортировка посылок», «Ритм».
