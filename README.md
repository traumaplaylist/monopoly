# Орбитальный капитал

Браузерная пошаговая экономическая настольная игра: покупайте колонии Солнечной системы, собирайте цветовые группы, стройте модули и станции, торгуйтесь и разоряйте соперников. Один живой игрок против 1–5 ботов, 3D-поле на Three.js.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # типизация + сборка в dist/
npm test           # модульные тесты движка и симуляция партий ботов
npm run e2e        # смоук-тест в Chromium (Playwright), сам собирает и поднимает preview
```

## Управление
- **Пробел** — бросить кубики / завершить ход.
- **Клик по клетке** — плашка клетки внизу поля; клик по плашке раскрывает карточку с арендой и кнопками строительства/залога.
- **«Ещё»** — журнал событий, активы, скорость ботов, выход в меню.
- **Мышь/палец** — вращение и зум поля.
- Партия сохраняется автоматически; «Продолжить» на стартовом экране.

## Структура
| Папка | Что внутри |
|---|---|
| `src/engine` | Чистое детерминированное ядро: `createGame(setup)`, `applyAction(state, action) → {state, events}`, `validate`, `getActor`. Без React/Three/DOM — переносится на сервер без изменений. |
| `src/bots` | ИИ ботов: `chooseBotAction(state, id) → Action`, через тот же API действий. |
| `src/game` | Клиент партии (`GameClient` → сейчас локальный), Zustand-стор, раннер ботов, сохранение. |
| `src/render` | 3D-сцена (React Three Fiber + drei): поле, фишки, постройки, кубики. |
| `src/ui` | Интерфейс поверх сцены: панели, аукцион, сделки, журнал. |
| `tests/unit` | Vitest: правила + 30 полных партий ботов с проверкой инвариантов и детерминизма. |
| `tests/e2e` | Playwright-смоук. |

Правила, упрощения и архитектурные решения — в [docs/DECISIONS.md](docs/DECISIONS.md).
